# `@los/ocr` — Монгол текст/танигчийн хэрэгсэл (`src/text`)

OCR extractor, банкны хуулгын parser, ангилагч (BSA-FR-2.2, FR-3.1, NFR-9) нийтээр ашиглах **цэвэр функцүүд** (I/O, цаг, санамсаргүй утга байхгүй).
`import { toMatchKey, parseMnAmount, … } from '@los/ocr'`. Хүснэгтийн өгөгдөл НЭГ газар: [`charmap.ts`](./charmap.ts).
PII (регистр, данс, нэр, гүйлгээний утга, OCR текст) хэзээ ч логлохгүй — шаардлагатай бол `maskForLog`.

## Функцүүд

| Функц | Үүрэг | Буруу оролтод |
| --- | --- | --- |
| `toMatchKey(s)` | Түлхүүр үг тааруулах канон түлхүүр (доорх хүснэгт). Идемпотент | `''` |
| `cyrillicToLatin(s)` | Кирилл → латин араг яс, том/жижиг хадгална (`Цалин` → `Tsalin`, `ЦАЛИН` → `TSALIN`) | хэвээр |
| `foldLatinLookalikesToCyrillic(s)` | `A B C E H K M O P T X Y a c e o p x y` → кирилл адил үсэг (регистр, шошго) | хэвээр |
| `normalizeWhitespace(s)` | Үл үзэгдэх тэмдэгт устгаж, бүх unicode зайг нэг зай болгож, тайрна | `''` |
| `parseMnAmount(s, opts?)` | Дүн → `number`. `1,234,567.89`, `1 234 567`, `1.234.567,89`, `(1,000.00)` = −1000, `1,000-`, `+/-`, `₮ MNT төг төгрөг` | `null` |
| `parseDateIso(s, opts?)` | Огноо → `YYYY-MM-DD` (хуанли шалгана) | `null` |
| `findDates(s, opts?)` | Мөр доторх бүх огноо: `{ iso, index, raw }[]` | `[]` |
| `parseTime(s)` | `HH:mm` / `HH:mm:ss` (`9:05`, `2:25 PM`, `14:25:07.123`) | `null` |
| `normalizeAccountNo(s)` | IBAN бол ТОМ ҮСЭГ зайгүй; дотоодын данс бол зөвхөн цифр | `''` |
| `isValidIban(s)` | Бүртгэлийн улсын урт + MN цифр бүтэц + шалгах цифр 02..98 + mod-97-10 | `false` |
| `parseRegisterNo(s)` | `{ valid, value, birthDate, gender }` | `valid: false`, бусад `null` |
| `namesMatch(a, b, opts?)` | `{ match, score }`, score 0..1, үгийн эрэмбэ үл хамаарна | `{ false, 0 }` |
| `maskForLog(s)` | `********03` — сүүлийн ≤ 2 тэмдэгтээс илүүг ил гаргахгүй | `''` |

### `toMatchKey` — алхмууд

1. NFKC (бүтэн өргөнтэй, лигатур, NBSP) → үл үзэгдэх тэмдэгт (`U+200B` г.м.) ба apostrophe (U+0027, U+2018, U+2019, U+02BC, backtick, U+00B4) УСТГАНА (үгийг таслахгүй).
2. **Холимог үг**: нэг үг дотор кирилл + латин байвал шийдвэрлэгч (look-alike БУС) үсгийн олонхиор бичгийн систем сонгож look-alike-ыг нэгтгэнэ
   (`цaлин`, латин `a` → кирилл; `Salаry`, кирилл `а` → латин; тэнцвэл кирилл). Том/жижиг мэдэрнэ (`B`→`В`, `b` хөндөгдөхгүй).
3. Жижиг үсэг (`Ө`→`ө`, `Ү`→`ү`), диакритик хасах (`é`→`e`, `ö`→`o`; кирилл `й`, `ё` хамгаалагдана).
4. Үсэг/цифр бус тэмдэгт → нэг зай (`Б.Болд` → `b bold`), зай нэгтгэх.
5. Кирилл → латин араг яс (хүснэгт), хүснэгтэд үгүй кирилл үсгийг хасна.
6. Латин хувилбарыг нугалж (доорх дүрэм) тогтворжтол давтана → `toMatchKey(toMatchKey(x)) === toMatchKey(x)`.

**Кирилл → латин араг яс** (`CYRILLIC_TO_LATIN`):

| Кирилл | Латин | Кирилл | Латин | Кирилл | Латин |
| --- | --- | --- | --- | --- | --- |
| а | a | й | i | ф | f |
| б | b | к | k | х | h |
| в | v | л | l | ц | ts |
| г | g | м | m | ч | ch |
| д | d | н | n | ш, щ | sh |
| е | e | о, ө | o | ъ, ь | (хоосон) |
| ё | o | п | p | ы | i |
| ж | j | р | r | э | e |
| з | z | с | s | ю | yu |
| и | i | т | t | я | ya |
| у, ү | u | | | | |

**Латин нугалах дүрэм** (`LATIN_FOLD_RULES`, дарааллаар): давхар үсэг нэг болно (`aa`→`a`) · `x`→`h` · `w`→`v` · `kh`→`h` · `zh`→`j` ·
`c`→`k` (а/о/у/к/л/р-ийн өмнө: `Capitron`, `Club`) эсвэл `s` (бусад: `Xac`, `Citi`; `ch` хэвээр) · `ye`→`e` · `yo`→`o` · `y` (`ya`/`yu`-аас бусад)→`i`.
Жишээ: `Хаан` = `Khan` = `Xaan` → `han`; `Капитрон` = `Capitron` → `kapitron`; `Жаргал` = `Zhargal` → `jargal`; `Хас` = `Xac` → `has`; `Ёндон` = `Yondon` → `ondon`; `Баатар` = `Batar` → `batar`.

Анхаарах: түлхүүр нь зөвхөн **тааруулахад** (уншигдахуйц биш: `QPay` → `qpai`); түлхүүр үг болон текст ХОЁУЛАНГ нь `toMatchKey`-ээр
дамжуулна. `XacBank` (зайгүй) → `hasbank`, `Хас банк` → `has bank` — substring тааруулахдаа зайгүй хувилбарыг мөн шалга.

### `parseMnAmount`

`parseFloat`-г түүхий оролт дээр ашиглахгүй: хэлбэрийг шалгаад зөвхөн цифрийн мөрийг `Number()`-д өгнө. Хоёрдмол `1.234` → аравтын 1.234,
`1,234` → мянгатын 1234 (`opts.decimalSeparator: '.' | ',' | 'auto'`-оор албадна). `null`: дүн биш, огноо/цаг, 15 цифрээс урт, `007` (тэгээр
эхэлсэн бүхэл = ID), мянгатын бүлэглэл зөрсөн (`12 34`, `5011 2345 6789`), хоёр тэмдэг (`(5)-`), 100 тэмдэгтээс урт.

### `parseDateIso` / `findDates` / `parseTime`

Дэмжих: `YYYY-MM-DD`, `YYYY/MM/DD`, `YYYY.MM.DD`, `DD.MM.YYYY`, `DD/MM/YYYY`, `DD-MM-YYYY`, `2026 оны 3 дугаар сарын 10[-ны өдөр]`,
ISO datetime угтвар (`…T12:30:45Z`; цагийн бүсийг хөрвүүлэхгүй). Жилийн хүрээ 1900–2100. 2 оронтой жил → `null` (таамаглахгүй).
`opts.order`: жил СҮҮЛД байгаа огноонд `'DMY'` (анхдагч) / `'MDY'`; `'YMD'` = эх сурвалж жил-эхэлсэн → жил сүүлд байвал `null`.
Жил эхэнд байвал үргэлж Y-M-D. `12/13/2026` (DMY) → `null` — сар/өдрийг солих таамаг хийхгүй.

### `parseRegisterNo`

Формат: 2 кирилл том үсэг (`А–Я`, `Ө`, `Ү`, `Ё`) + 8 цифр. Зай/зураас/цэг, жижиг үсгийг тэвчиж, үсгийн хэсэгт латин look-alike-ыг кирилл болгоно;
цифрийн хэсэгт OCR андуурал (`O`→0, `I`/`l`→1, `S`→5, `B`→8) зөвхөн **засаад бүтэн дугаар зөв болох үед** засна. `UB…` гэх мэт латин транслитыг таамаглахгүй.

* Төрсөн огноо = `YYMMDD`; сар 01–12 → 19YY, сар 21–32 (сар+20) → 20YY; бусад сар буруу.
* Хүйс = 8 цифрийн **7-р цифр**: сондгой → `M`, тэгш → `F` (docs-д заагаагүй ТАМААГ — `DECISIONS.md`).
* **Нэг тогтвортой дүрэм**: огноо хуанлийн хувьд буруу бол БҮТЭН дугаар `valid: false`, `value`/`birthDate`/`gender` гурвуулаа `null`.
  `valid: true` үед гурвуулаа заавал утгатай.

### `namesMatch`

Үг бүрийг `toMatchKey`-ээр хувиргаж, эрэмбэ үл хамааран хомхой зэрэгцүүлнэ. Оноо = жинлэсэн Dice: `2·Σ(ижилсэл·жин) / (ΣжинA + ΣжинB)`;
бүтэн үгийн жин 1, эхний үсэг 0.5 (`Б.Болд`), эхний үсэг ↔ бүтэн үг ижилсэл 0.9. 5+ тэмдэгтийн үгэнд 1 шивэлтийн алдаа (ижилсэл ≥ 0.8) тэсвэрлэнэ.
Дэнслэл (`Бат-Эрдэнэ` ↔ `Бат Эрдэнэ` ↔ `Батэрдэнэ`) хоёр хувилбараар үнэлэгдэж, илүү сайныг авна. **Заавал**: ≥ 1 БҮТЭН үг таарах
(зөвхөн эхний үсгүүд таарвал `match: false`). `match = score ≥ minScore` (анхдагч 0.8, `NAMES_MATCH_DEFAULTS`).
Мэдэгдэж буй хязгаарлалт: генитив (`Батын` ↔ `Бат`) нормчлогддоггүй; 200 тэмдэгтээс урт оролт нэр биш → `{ false, 0 }`.

### `isValidIban`

Улсын урт нь SWIFT IBAN бүртгэлээс (`IBAN_LENGTHS`); **Монгол (MN) = 20** (`MN` + 2 шалгах + 4 банкны код + 12 данс, зөвхөн цифр).
Бүртгэлд байхгүй улс → `false`. Кирилл look-alike (`М`) латин болно.

## Аюулгүй байдал / гүйцэтгэл

Бүх regex хязгаарлагдмал квантортой, оролтын дээд урттай (`amount` 100, `date` 100, `account` 64, `register` 40, `names` 200) тул 100k тэмдэгтийн
адверсари мөр шугаман хугацаанд (≤ секунд) боловсруулагдана — тест нь цагийн төсөвтэйгээр шалгана.
