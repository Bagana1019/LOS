# OCR туршилтын fixture-ууд (ЗОХИОМОЛ / SYNTHETIC)

**Энэ хавтасны БҮХ зураг ЗОХИОМОЛ.** Бодит хүн, байгууллага, регистр, данс, утас байхгүй: нэрс зохиомол, регистр
`ЖЮ85061512`/`УБ92110384` нь формат ба төрсөн огноо нь зөв боловч бодит хүнийх биш. Бодит иргэний үнэмлэх, цалингийн
тодорхойлолт, банкны хуулгын зураг энд ОРУУЛЖ БОЛОХГҮЙ (PII; CLAUDE.md §3.2(10)).

Зургуудыг `generate_fixtures.py` (Python + Pillow, DejaVu Sans фонт) зурсан тул **цэвэр, компьютер зурсан** текст. Бодит
иргэний үнэмлэхийн хамгаалалтын хээ, гялбаа, голограмм, загварлаг фонт, камерын гажилт эндээс ЭСВЭЛ тестээс ХАМААРАХГҮЙ:
бодит зураг дээрх нарийвчлал эндхээс илүү муу байна.

## Дахин үүсгэх

```bash
python3 -I packages/ocr/test-fixtures/generate_fixtures.py            # энэ хавтас руу
python3 -I packages/ocr/test-fixtures/generate_fixtures.py /tmp/out   # өөр хавтас руу
```

Шаардлага: Python 3, Pillow, `/usr/share/fonts/truetype/dejavu/DejaVuSans*.ttf`. Seed тогтмол, цаг ашиглаагүй, PDF-ийн
огноо тогтмол. Pillow/фонтын хувилбар өөр бол пикселүүд бага зэрэг өөр гарч болно (тест зөвхөн доорх найдвартай талбарыг шалгана).

## Бодит Tesseract 5.3.4 (`mon+eng`, `--psm 6`, 300 dpi) дээрх нарийвчлал

Интеграцийн тест (`src/integration/tesseract.integration.test.ts`) tesseract болон `mon` хэл олдохгүй бол өөрөө алгасна
(`apt install tesseract-ocr tesseract-ocr-mon tesseract-ocr-eng poppler-utils`). Дэлгэрэнгүй хүснэгт: `OCR_REPORT=1 npx vitest run src/integration`.

Эдгээр 5 зураг дээрх гараар тооцсон 33 талбарын **31 нь яг зөв**; үлдсэн 2:

1. `id-card-stacked.png`: регистрийн `Б` нь латин `B` болж `УВ92110384` гэж уншигдсан (`alternatives`-д зөв `УБ92110384` бий).
2. `salary-certificate-photo.jpg`: регистр уншигдсангүй (`null`).

### Найдвартай (тест шалгана)

Овог/нэр, төрсөн огноо, хүчинтэй хугацаа (expiry), сарын цалингийн дүн, тодорхойлолтын огноо, хугацааны сарын тоо, байгууллагын
нэр, ажилтны нэр.

### Найдваргүй (шалгахгүй / зөвхөн alternatives, note-той)

- **Регистрийн үсэг**: OCR заримдаа илүү үсэг нэмдэг (`ЖЮЗ`, `ЖЮӨ`: задлагч эхний 2 үсгийг авч note тавина), `Б`/`В`/`B` мөн андуурна.
  Цифрүүд ба төрсөн огнооны шалгалт (хүйс, он/сар/өдөр) найдвартай тул `alternatives` + "хүн шалгана" гэж тэмдэглэнэ.
- **Үнэмлэхний дугаарын үсэг**: `MN` нь `ММ` (кирилл) гэж ойлгогдож болно (PDF-д ажиглагдсан).
- **Албан тушаалын өгүүлбэр**, зургийн (photo) хувилбар дээр: хэсэгчлэн алдагдаж болно.
- **Хүйс** (photo): шошго эвдэрвэл регистрийн цифрээс тооцоолж `derived` гэж тэмдэглэнэ.
- Хүчтэй эвдсэн зураг (2.5° эргэлт + 0.5 масштаб + JPEG q=40) шошгонуудын ихэнхийг алддаг тул fixture-д ОРУУЛААГҮЙ.

Дундаж итгэл 0.89..0.94, нэг зураг 0.3..0.7 сек, 2 хуудастай PDF ~2.4 сек (энэ орчинд). Эдгээр нь **зохиомол цэвэр** зураг дээрх
тоо; бодит иргэний үнэмлэх/хуулгын зураг дээр баталгаагүй (`TODO(samples)`).
